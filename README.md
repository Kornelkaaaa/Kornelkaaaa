<div align="center">

*Student-athlete at West Virginia University building full-stack AI applications.*

## 🚀 Featured Projects

<details open>
<summary><b>🎮 Game Recommender (MIST 460)</b></summary>

<br/>

3-tier game recommendation system combining classical SQL recommendations **and** AI-powered semantic search. Embeds reviews and descriptions with OpenAI, runs cosine-similarity vector search in SQL Server, and uses GPT-4o-mini as an advisor to rank and explain matches. Includes a developer analytics dashboard.

| Aspect | Detail |
|---|---|
| **Stack** | FastAPI · Streamlit · SQL Server (VECTOR) · OpenAI · pymssql |
| **Architecture** | 3-tier (UI → API → DB) |
| **AI Approach** | Embedding generation + cosine-similarity vector search + LLM ranking |
| **Extra** | Developer analytics dashboard |
| **Repository** | [View on GitHub →](https://github.com/Kornelkaaaa/MIST460_GroupProject_Group1) |

</details>

<summary><b>🌸 Course Recommender</b></summary>

<br/>

|---|---|
| **Stack** | FastAPI · Streamlit · SQL Server · OpenAI · LangChain · Azure |
| **AI Approach** | Job-description → embedding search → GPT-4o ranking + justification |
| **Features** | Prerequisite checking, course-section lookup |
| **Live Demo** | [Open the app →](https://mist460-ui-buszka.streamlit.app/) |
